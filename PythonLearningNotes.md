# Python Learning Notes

## Переменные и вывод
Переменные нужны для хранения данных в программе. Через `print()` обычно выводят результат в консоль, а через `input()` получают данные от пользователя.

- Переменная - `name = "Alice"`
- Число - `age = 25`
- Вывод в консоль - `print(name, age)`
- Получение ввода - `user_name = input("Введите имя: ")`
- Преобразование типа - `number = int("10")`

## Типы данных
Типы данных определяют, что именно хранится в переменной: число, текст, логическое значение и так далее. Это база, без которой дальше работать с Python неудобно.

- `int` - `x = 10`
- `float` - `price = 19.99`
- `str` - `text = "Привет"`
- `bool` - `is_ready = True`
- `NoneType` - `result = None`

## Строки
Строки используются для хранения текста. В Python строки поддерживают индексы, срезы и много полезных методов для обработки текста.

- Обычная строка - `message = "Hello"`
- Многострочная строка - `text = """Строка 1\nСтрока 2"""`
- Конкатенация - `full = "Hi, " + name`
- Повторение - `line = "-" * 10`
- Длина строки - `len(message)`
- Доступ по индексу - `message[0]`
- Срез - `message[0:3]`
- Форматирование f-string - `f"Меня зовут {name}"`
- Методы строки - `message.lower()`, `message.upper()`, `message.strip()`

## Арифметика
Python умеет выполнять все основные математические операции. Это используется в вычислениях, формулах, циклах и повседневной логике программ.

- Сложение - `a + b`
- Вычитание - `a - b`
- Умножение - `a * b`
- Деление - `a / b`
- Целочисленное деление - `a // b`
- Остаток от деления - `a % b`
- Степень - `a ** b`

## Сравнение и логика
Операторы сравнения позволяют сравнивать значения, а логические операторы помогают объединять условия. Обычно они используются внутри `if`, `while` и фильтрации данных.

- Равно - `a == b`
- Не равно - `a != b`
- Больше - `a > b`
- Меньше или равно - `a <= b`
- И - `a > 0 and b > 0`
- Или - `a > 0 or b > 0`
- Не - `not is_ready`

## Условные конструкции
Условия позволяют программе принимать решения. С их помощью можно выполнять разный код в зависимости от значения переменных или результата проверки.

- Простое условие -
  ```python
  if age >= 18:
      print("Совершеннолетний")
  ```
- Несколько веток -
  ```python
  if score >= 90:
      print("A")
  elif score >= 75:
      print("B")
  else:
      print("C")
  ```

## Списки
Список это изменяемая коллекция элементов. Он подходит, когда нужно хранить несколько значений в одном месте и работать с ними по индексам.

- Создание списка - `numbers = [1, 2, 3]`
- Доступ к элементу - `numbers[0]`
- Изменение элемента - `numbers[1] = 10`
- Добавление элемента - `numbers.append(4)`
- Вставка элемента - `numbers.insert(1, 99)`
- Удаление элемента - `numbers.remove(2)`
- Удаление по индексу - `numbers.pop(0)`
- Длина списка - `len(numbers)`
- Срез списка - `numbers[1:3]`

## Кортежи
Кортеж это коллекция, похожая на список, но после создания она не изменяется. Кортежи удобны для хранения фиксированных наборов данных, например координат или настроек.

- Создание кортежа - `point = (10, 20)`
- Доступ к элементу - `point[0]`
- Распаковка - `x, y = point`

## Словари
Словарь хранит данные в формате `ключ: значение`. Это удобно, когда у каждого значения есть понятное имя, например у пользователя есть `name`, `age`, `city`.

- Создание словаря - `user = {"name": "Anna", "age": 20}`
- Получение значения - `user["name"]`
- Безопасное получение - `user.get("email", "нет данных")`
- Добавление пары - `user["city"] = "Kyiv"`
- Удаление пары - `user.pop("age")`
- Ключи - `user.keys()`
- Значения - `user.values()`
- Пары ключ-значение - `user.items()`

## Множества
Множество хранит только уникальные элементы. Оно полезно, когда нужно быстро проверить наличие значения или убрать дубликаты.

- Создание множества - `unique_numbers = {1, 2, 3}`
- Добавление элемента - `unique_numbers.add(4)`
- Удаление элемента - `unique_numbers.remove(2)`
- Проверка наличия - `3 in unique_numbers`

## Циклы
Циклы нужны для повторения одного и того же действия несколько раз. `for` обычно используют для перебора коллекций, а `while` для повторения по условию.

- Цикл `for` -
  ```python
  for item in [1, 2, 3]:
      print(item)
  ```
- Цикл `while` -
  ```python
  count = 0
  while count < 3:
      print(count)
      count += 1
  ```
- Пропуск итерации - `continue`
- Выход из цикла - `break`

## `range`
`range()` часто используется в циклах для генерации последовательности чисел. Он помогает удобно задавать начало, конец и шаг перебора.

- От 0 до 4 - `range(5)`
- От 1 до 4 - `range(1, 5)`
- С шагом 2 - `range(0, 10, 2)`

## Функции
Функции позволяют переиспользовать код и делать программу более понятной. В них можно передавать аргументы и возвращать результат через `return`.

- Простая функция -
  ```python
  def greet(name):
      return f"Привет, {name}"
  ```
- Аргумент по умолчанию -
  ```python
  def power(number, degree=2):
      return number ** degree
  ```
- Именованные аргументы - `power(number=3, degree=3)`
- Лямбда - `square = lambda x: x * x`

## Исключения
Исключения помогают обрабатывать ошибки без падения программы. Это особенно полезно при вводе данных, работе с файлами и сетевыми запросами.

- Обработка ошибки -
  ```python
  try:
      number = int(input("Введите число: "))
  except ValueError:
      print("Это не число")
  finally:
      print("Завершение")
  ```

## Импорт модулей
Модули позволяют использовать готовые инструменты из стандартной библиотеки или других файлов. Это помогает не писать всё с нуля.

- Импорт всего модуля - `import math`
- Импорт конкретной функции - `from math import sqrt`
- Псевдоним модуля - `import random as rnd`

## Работа с файлами
Работа с файлами нужна, когда программа должна читать или сохранять данные. Конструкция `with open(...)` автоматически закрывает файл после работы.

- Чтение файла -
  ```python
  with open("data.txt", "r", encoding="utf-8") as file:
      content = file.read()
  ```
- Запись в файл -
  ```python
  with open("data.txt", "w", encoding="utf-8") as file:
      file.write("Привет")
  ```

## Списковые включения
Списковые включения позволяют создавать списки коротко и читаемо. Это удобный способ заменить небольшой цикл для построения нового списка.

- Создание списка в одну строку - `squares = [x * x for x in range(5)]`
- С условием - `evens = [x for x in range(10) if x % 2 == 0]`

## Классы
Классы используют в объектно-ориентированном программировании. Они помогают объединять данные и действия над ними в одну структуру.

- Простой класс -
  ```python
  class Person:
      def __init__(self, name):
          self.name = name

      def say_hello(self):
          return f"Привет, я {self.name}"
  ```
- Создание объекта - `person = Person("Anna")`
- Вызов метода - `person.say_hello()`

## Полезные встроенные функции
Python содержит много готовых функций, которые часто используются в повседневном коде. Их полезно запомнить, потому что они сильно ускоряют работу.

- Максимум - `max([1, 5, 3])`
- Минимум - `min([1, 5, 3])`
- Сумма - `sum([1, 2, 3])`
- Сортировка - `sorted([3, 1, 2])`
- Перечисление индексов - `enumerate(["a", "b"])`
- Объединение последовательностей - `zip([1, 2], ["a", "b"])`

## Проверки
Проверки позволяют определить тип данных, наличие элемента или истинность значения. Это базовая часть логики почти в любой программе.

- Проверка типа - `isinstance(10, int)`
- Проверка наличия в коллекции - `"a" in "cat"`
- Проверка истины - `if items:`

## Комментарии
Комментарии делают код понятнее для человека. Они не выполняются интерпретатором и используются для пояснений или документации.

- Однострочный комментарий - `# Это комментарий`
- Докстрока функции -
  ```python
  def add(a, b):
      """Возвращает сумму двух чисел."""
      return a + b
  ```
